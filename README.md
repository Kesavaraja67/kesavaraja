# Interactive Portfolio - Kesavaraja M.

Welcome to my personal portfolio! This project is a neo-brutalist and skeuomorphic web experience that showcases my skills, experience, and journey as a Full-Stack Developer. It features a fully interactive web terminal emulator built directly into the browser.

**[Live Site](https://kesavaraja.vercel.app)**

## Features

- **Interactive Terminal:** An actual working web terminal emulator with commands like `help`, `about`, `skills`, `projects`, and even a built-in calculator and weather checker.
- **Neo-brutalist & Skeuomorphic Design:** A blend of bold, high-contrast layouts and tactile, real-world elements like torn paper, wax seals, and treasure maps.
- **Responsive Architecture:** Built with semantic HTML, CSS, and vanilla JavaScript without any heavy external frameworks.
- **Leaflet Map Integration:** An interactive geographical map plotting my journey and locations.

## About Me

I'm a passionate Computer Science undergraduate at SRMIST, deeply focused on building production-grade software across the full stack. I have hands-on experience shipping SaaS PWAs, engineering Java Spring Boot microservices, and contributing heavily to open-source AI Linux projects.

## Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript
- **Mapping:** Leaflet.js
- **Typography:** Google Fonts (Space Grotesk, Space Mono, Caveat, Playfair Display)
